0/1 Knapsack Algorithm

The 0/1 Knapsack Problem is a classic dynamic programming problem where you must select a subset of items to maximize value while staying within a weight capacity.

Steps:

  • Create a DP table where dp[i][w] represents the maximum value achievable with the first i items and weight capacity w.
  • For each item and weight, decide whether to include the item (if it fits) or exclude it, taking the maximum value.
  • Backtrack through the table to find the selected items.

Time Complexity: O(n * capacity)

Space Complexity: O(n * capacity)
